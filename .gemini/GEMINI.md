# 사용자 설정

이 파일은 AI 어시스턴트(Gemini)가 따라야 할 사용자 정의 규칙을 명시합니다.

1. **언어**: 모든 대답은 한국어로만 합니다.
2. **문서 작성**: 모든 마크다운(.md) 파일은 항상 한국어로 작성합니다.
3. **실행 환경**: 모든 쉘 명령은 항상 `.venv` 환경에서 실행합니다.
4. **용량 관리**: 명령 실행 전 디스크 용량을 확인하며, 모델 학습 시 체크포인트 저장은 지양합니다.
5. **다운로드 경로**: 모델, 데이터셋 등 모든 파일 다운로드는 반드시 `/data` 하위 경로에 저장합니다. `/root`나 다른 경로에 저장하면 서버 용량 부족으로 시스템이 불안정해질 수 있습니다.
